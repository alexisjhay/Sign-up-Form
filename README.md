<h1>Sign Up Form</h1>
<p> This project is a <strong>Sign-Up Form</strong> created as part of <strong>The Odin Project</strong> curriculum. The goal of this project is to practice building forms with HTML and CSS with a user-friendly interface. </p>

<h2>Features</h2>
<ul>
<li>User-friendly sign-up interface</li>
<li>Input fields for registration details</li>
<li>Basic form validation</li>
<li>Responsive design for desktop and mobile devices</li>
<li>Clean and simple layout</li>
</ul>

<h2>Technologies Used</h2>
<ul>
<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript</li>
</ul>

<h2>Future Improvements</h2>
<ul>
<li>Implement password confirmation</li>
<li>Add stronger password validation</li>
<li>Display detailed validation messages</li>
</ul>

<h2>Learning</h2>

<p> This project helped me practice creating forms, styling form elements, handling user input using HTML and CSS. </p>
